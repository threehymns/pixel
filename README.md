# PixelForge Studio

PixelForge Studio is a powerful, professional-grade pixel art and animation editor built with React and TypeScript. It offers a comprehensive suite of tools for creating high-quality pixel art, from simple sprites to complex animations.

## Features

### 🎨 Drawing Tools
- **Pencil & Eraser**: Precise pixel placement and removal.
- **Shapes**: Rectangle, Ellipse, and Line tools with filled and outline modes.
- **Fill Tool**: Contiguous and non-contiguous flood fill.
- **Eyedropper**: Quickly pick colors from your canvas.
- **Advanced Brushes**: Smudge, Blur, and Sharpen for detailed texture work.

### ✨ Advanced Editing
- **Symmetry**: Real-time horizontal and vertical symmetry.
- **Ink Types**: 
  - **Simple**: Standard pixel drawing.
  - **Shading**: Use custom shade ramps for smooth gradients and lighting.
- **Pixel Perfect**: Clean up your lines automatically for that perfect pixel art look.
- **RotSprite**: High-quality rotation algorithm specifically designed for pixel art.

### 🖼️ Project Management
- **Layers**: Organize your work with multiple layers, visibility toggles, and locking.
- **Timeline**: Create animations with a frame-based timeline, including onion skinning for smooth transitions.
- **History**: Full undo/redo support with a dedicated history panel.
- **Palette Management**: Create, import, and manage color palettes.

### 🛠️ Workspace
- **Customizable Layout**: Resizable panels for layers, history, palette, and timeline.
- **File System**: Integrated file tree for managing your projects.
- **Preview**: Real-time animation preview.
- **Grid**: Toggleable pixel grid for precision.

## Getting Started

1. **Create a Project**: Start fresh or import an existing project from the Home screen.
2. **Select a Tool**: Use the toolbar on the left to choose your drawing tool.
3. **Pick a Color**: Use the palette or color picker to select your primary and secondary colors.
4. **Draw**: Start creating on the central canvas.
5. **Animate**: Use the timeline at the bottom to add frames and bring your art to life.
6. **Export**: Save your frames or full project using the export options.

## Tech Stack
- **React**: UI library.
- **TypeScript**: Type-safe development.
- **Tailwind CSS**: Modern utility-first styling.
- **Lucide React**: Beautiful, consistent iconography.
- **Allotment**: Flexible, resizable split-pane layouts.
- **Framer Motion**: Smooth animations and transitions.

- `B`: Pencil
- `E`: Eraser
- `G`: Fill
- `I`: Eyedropper
- `L`: Line
- `U`: Shape Tools
- `V`: Move Tool
- `S`: Smudge Tool
- `R`: Effect Brushes
- `Ctrl+Z`: Undo
- `Ctrl+Y`: Redo
- `X`: Swap Colors
